# Planspiel-Kommunikationskarte

## Start

Öffne `index.html` mit einem Doppelklick. Die Anwendung startet im Browser.

Für einen ersten Überblick kannst du über **Import** die Datei `beispielnachrichten.json` laden. Achtung: Ein Import ersetzt den aktuellen Stand.

## Nachrichten

- **＋ Nachricht** fügt eine Nachricht hinzu.
- Klicke auf einen Pfeil, um eine Nachricht zu ändern.
- Klicke auf eine Partei, um sie zu bearbeiten. Über **＋** neben der Parteienliste kannst du eine Partei hinzufügen.
- Zum Löschen wirst du vorher gefragt.

## Filtern

- Wähle links eine oder mehrere Parteien aus. Bei einer Partei siehst du ihre direkten Kontakte; bei mehreren nur Nachrichten zwischen den ausgewählten Parteien.
- Nutze Suche, Kategorien und Uhrzeiten, um die Ansicht weiter einzugrenzen.
- **Zurücksetzen** zeigt wieder alles.

## Zeitverlauf

Ziehe den Regler unten, um Nachrichten im Tagesverlauf zu sehen. Mit **▶** startest du, mit **Ⅱ** pausierst du. Mit **■** springst du zum Anfang.

## Speichern

Änderungen werden automatisch in diesem Browser gespeichert.

Für eine zusätzliche Sicherung klickst du oben auf **current.json**, wählst die Datei `current.json` aus und erlaubst den Zugriff. Danach wird sie automatisch aktualisiert. Beim ersten Verbinden wird der aktuelle Stand in die Datei geschrieben.

Mit **Export** kannst du jederzeit eine Sicherung herunterladen. **Drucken** öffnet eine Druckansicht.
